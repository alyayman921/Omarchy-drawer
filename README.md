# Plugin Drawer

Collapse plugins into a drawer to keep the Omarchy bar clean.


## Features

- Hide any bar widget into a compact drawer button without disabling it.
- Drag to reorder hidden widgets inside the drawer.
- Edit which widgets are hidden from a checkbox list.

## Requirements

- Omarchy (Quattro shell) with a bar.

## Install

```sh
omarchy plugin add https://github.com/alyayman921/Omarchy-drawer.git --enable
```

## Usage
- Make sure the Plugin is enabled first from the Omarchy menu.
- Left-click the drawer button to open or close the menu.
- In the drawer list, click an entry to open that widget's panel.
- Click the pen icon to edit which widgets are hidden. Check or uncheck widgets, exit to save all at once, might lag alittle..

## Remove

```sh
omarchy plugin remove 3lymn.plugin-drawer
```
